# 후기 유형: 여행 · 숙소

> `/review`가 사진과 설명에서 못 읽어낸 항목만 골라 물어봅니다.
> 항목을 추가·삭제해서 자유롭게 고치세요.

## 반드시 필요 (없으면 글이 안 됨)
- 어디를 / 언제 (며칠, 몇 박)
- 누구와 (혼자·커플·가족·친구)
- 동선 — 어디서 어디로, 순서대로

## 물어볼 것
- 비용 — 총 얼마 썼는지, 항목별로 기억나는 만큼 (숙소·교통·식비)
- 교통 — 어떻게 갔는지, 현지 이동은 뭘로 했는지
- 숙소 — 어디 묵었는지, 컨디션·위치·가격 대비 만족도
- 날씨·시즌 — 그때 날씨, 그 시기에 가는 게 어땠는지
- 하이라이트 — 제일 좋았던 순간 하나
- 아쉬운 점 / 실수한 것 — 다음에 가면 안 할 것
- 팁 — 가기 전에 알았으면 좋았을 것

## 검색으로 채울 것 (사용자에게 묻지 말 것)
- 입장료, 운영시간, 휴무일
- 대중교통 노선·소요시간
- 예약 필수 여부
- 확인 안 되면 `[확인 필요: ...]`로 남긴다
