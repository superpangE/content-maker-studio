# 후기 유형: 장소 · 전시 · 공연

> `/review`가 사진과 설명에서 못 읽어낸 항목만 골라 물어봅니다.
> 항목을 추가·삭제해서 자유롭게 고치세요.

## 반드시 필요 (없으면 글이 안 됨)
- 뭘 봤는지 (전시명·공연명·장소명)
- 언제 갔는지
- 어땠는지 — 인상에 남은 것 하나는 구체적으로

## 물어볼 것
- 티켓 — 얼마였는지, 어디서 예매했는지, 현장 구매 가능했는지
- 소요 시간 — 얼마나 머물렀는지
- 혼잡도 — 사람 많았는지, 언제 가면 한산한지
- 동선 — 어떤 순서로 보는 게 좋은지
- 사진 촬영 — 가능했는지, 제한이 있었는지
- 누구랑 가면 좋을지 / 아이 동반 괜찮은지
- 아쉬운 점

## 검색으로 채울 것 (사용자에게 묻지 말 것)
- 전시·공연 기간, 운영시간, 휴관일
- 정가 티켓 가격, 예매처
- 위치·교통편
- 확인 안 되면 `[확인 필요: ...]`로 남긴다
