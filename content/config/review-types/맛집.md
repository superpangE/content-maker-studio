# 후기 유형: 맛집 · 카페

> `/review`가 사진과 설명에서 못 읽어낸 항목만 골라 물어봅니다.
> 이미 사진에 있는 건 묻지 않습니다 (메뉴판이 있으면 가격은 안 물어봄).
> 항목을 추가·삭제해서 자유롭게 고치세요.

## 반드시 필요 (없으면 글이 안 됨)
- 상호명 / 위치 (동네 수준이라도)
- 뭘 먹었는지
- 맛이 어땠는지 — **구체적으로.** "맛있었다"는 후기가 아니라 감탄사다.
  (짠지 싱거운지, 식감, 향, 양, 기대와 비교해서)

## 가장 먼저 물을 것 — 그 집만의 것

검색(Scout 단계)에서 알아낸 **이 집 고유의 방식**이 어땠는지 묻는다.
직접 구워 먹는 집이면 굽는 게 어땠는지, 소스를 안 주는 집이면 그렇게 먹는 게
어땠는지, 오마카세면 코스 흐름이 어땠는지.

**이게 후기의 알맹이다.** 아래 일반 항목들이 자리를 다 차지하게 두면, "고기가
연했어요" 같은 아무 집에나 쓸 수 있는 글이 나온다. 실제로 그렇게 한 번 실패했다.

## 물어볼 것
- 가격 — 총 얼마 나왔는지 (사진에 영수증·메뉴판 있으면 생략)
- 웨이팅 — 얼마나 기다렸는지, 언제 갔는지 (평일/주말, 시간대)
- 분위기 — 혼자/데이트/가족/단체 중 어디에 맞는지
- 주차 — 됐는지, 발렛인지, 근처 유료주차장인지
- 서비스 — 응대가 기억에 남았는지 (좋든 나쁘든)
- 아쉬운 점 — 하나는 있어야 광고로 안 읽힌다
- 재방문 의사 — 다시 갈 건지, 누구랑 가면 좋을지

## 검색으로 채울 것 (사용자에게 묻지 말 것)
- 정확한 주소, 영업시간, 휴무일
- 예약 가능 여부 / 예약 수단
- 확인 안 되면 `[확인 필요: ...]`로 남긴다
