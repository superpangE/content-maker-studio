# 후기 유형: 제품 · 서비스

> `/review`가 사진과 설명에서 못 읽어낸 항목만 골라 물어봅니다.
> 항목을 추가·삭제해서 자유롭게 고치세요.

## 반드시 필요 (없으면 글이 안 됨)
- 제품명 / 모델명 (사진에 박스·라벨 있으면 거기서 읽는다)
- 얼마나 써봤는지 — 하루 써본 것과 석 달 써본 건 무게가 다르다
- 왜 샀는지 — 어떤 문제를 풀려고 산 건지

## 물어볼 것
- 가격 — 얼마에 어디서 샀는지 (할인가면 정가도)
- 좋은 점 — 실제로 쓰면서 체감한 것 (스펙 나열 말고)
- 불편한 점 — 하나는 있어야 광고로 안 읽힌다
- 비교 — 전에 쓰던 것 / 같이 고민한 제품이 있었는지
- 이런 사람한테 맞다 / 이런 사람은 사지 마라
- 재구매 의사

## 검색으로 채울 것 (사용자에게 묻지 말 것)
- 공식 스펙, 정가, 출시 시기
- 구성품, A/S 조건
- 확인 안 되면 `[확인 필요: ...]`로 남긴다

## 주의
- 협찬·제공받은 제품이면 **반드시 글에 명시한다.** 사용자에게 물어보고,
  협찬이면 본문에 표기 문구를 넣는다 (공정위 표시 의무).
