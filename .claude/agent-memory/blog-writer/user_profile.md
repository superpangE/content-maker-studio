운영자는 한국어 콘텐츠 스튜디오의 오케스트레이터다. 블로그 포스트를 생산하며, 주제는 KBO 라운드업처럼 스포츠·연예·트렌드 집계 콘텐츠가 중심이다. 타겟 독자는 20-40대 캐주얼 팬.

주요 플랫폼: 네이버 블로그, 티스토리/워드프레스.

**How to apply:** 글쓰기 시 항상 소스 기반으로 작성하고, 플랫폼 전환은 seo-editor가 담당하므로 master draft에서는 SEO 포맷을 신경 쓰지 않는다.
