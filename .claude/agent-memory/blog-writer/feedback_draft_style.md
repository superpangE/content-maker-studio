sources.md (또는 프롬프트에 직접 제공된 소스 블록)만을 사실의 근거로 사용한다. 훈련 데이터 기억에서 통계·사실을 꺼내지 않는다.

**Why:** 집계 콘텐츠 스튜디오의 핵심 원칙 — 출처 없는 사실은 오보 위험이 있고 브랜드 신뢰를 해친다.

**How to apply:** 소스에 없는 수치나 사건은 [확인 필요: ...]로 명시. 소스에 있는 내용만 자신 있게 서술.

---

두괄식 구조, 한 문단 한 메시지, 존댓말, AI 상투어 금지. 이미지 자리는 [이미지: 설명] 형식으로 삽입. 클로징은 여운 있게, 요약 나열 금지.

**Why:** brand-voice.md에 명시된 규칙 + 사용자가 brief에서 반복 확인한 방향.

**How to apply:** 모든 드래프트에 동일하게 적용. 섹션 길이는 outline 글자 수 가이드를 준수.
